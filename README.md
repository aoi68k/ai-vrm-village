# ai-vrm-village

ボクセル箱庭 × VRMアバター × GOAP自律型手助けNPCが融合した、クォータービュー・マルチプレイヤーWebゲームです。

🎮 **ブラウザで遊ぶ (GitHub Pages)**:  
👉 **[https://aoi68k.github.io/ai-vrm-village/](https://aoi68k.github.io/ai-vrm-village/)**

---

## 🎮 基本操作

| 操作 | アクション |
| :--- | :--- |
| **W / A / S / D** | キャラクター移動（現在のカメラ視点と完全連動） |
| **右クリックドラッグ** | **カメラ視点の360度水平回転（左右に旋回）** |
| **左クリックドラッグ** | **カメラ位置の自由移動（地面を掴んでパン）** |
| **マウスホイール** | 視点のズームイン / ズームアウト（拡縮） |
| **E キー / 右上ボタン** | **ワールド編集モードの開閉 (GUI展開)** |
| **左短クリック** | ボックス追加（配置） *(※編集モード時)* |
| **右短クリック** | ボックス削除（破壊） *(※編集モード時)* |
| **数字キー 1〜6** | ブロック素材の切り替え（草地・土・石・原木・葉・木板） |
| **VRMドラッグ＆ドロップ** | 手元の `.vrm` ファイルを画面に落とすだけでアバター即時変更 |

## 💻 ローカル環境での起動手順

```bash
# 1. 依存ライブラリのインストール
npm install

# 2. クライアントの起動 (Three.js / Vite)
npm run dev:client
# -> ブラウザで http://localhost:5173 を開きます (ソロモードで即遊べます)

# 3. マルチプレイヤー＆GOAPサーバーの起動 (Colyseus) ※任意
npm run dev:server
# -> ws://localhost:2567 でリアルタイム同期サーバーが起動します
```

## 🌐 マルチプレイサーバーのデプロイ (Render.com)

本リポジトリには Render.com 用の設定ファイル `render.yaml` が同梱されており、無料枠でサーバーを公開できます。

1. [Render.com](https://render.com/) にログインし、**New +** → **Blueprint** を選択します。
2. 本リポジトリ (`ai-vrm-village`) を選択すると、`render.yaml` が自動認識されます。
3. **Apply** をクリックすると、自動で `npm install` および `npm start` (Colyseusサーバー) がビルド・デプロイされます。
4. 発行された URL (例: `https://ai-vrm-village.onrender.com`) をゲーム内の **「プロフィール設定」→「🌐 マルチプレイ・サーバー接続設定」** に入力、または URL 末尾に `?server=https://your-service.onrender.com` を付けてアクセスすると接続完了です。

## 🛠️ 主な機能
- **VRMアバター**: 自然な立ち姿待機モーション、関節連動歩行、採掘/設置アクション、自動まばたき。
- **開閉式ワールド編集GUI**: 半透明ゴーストプレビュー、1x1〜3x3ブラシ、ワンクリック建築スタンプ（木、東屋、石垣、階段）。
- **内蔵効果音 (Web Audio API)**: 音声ファイル不要の即時シンセサイズSE（破壊音、設置音、通知音）。
- **GOAP手助けNPC**: プレイヤーの採掘・建築作業を感知し、最優先でお手伝いに駆けつける自律AI「お手伝いピコ」。
